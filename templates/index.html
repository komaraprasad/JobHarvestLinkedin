Set up the JobHarvest extensionOne time, about 1 minute. Works in Microsoft Edge and Google Chrome.
⬇ Download extension (.zip)
  1. Unzip the downloaded file (right-click → Extract All). Keep the folder somewhere permanent, e.g. Documents.
  2. Open edge://extensions in a new tab (Chrome: chrome://extensions).
  3. Turn on Developer mode (Edge: left side · Chrome: top right).
  4. Click Load unpacked and choose the folder you unzipped (the one that contains manifest.json).
  5. Sign in to LinkedIn in this same browser.
  6. Come back here and press F5. This box turns green: Extension connected.
To update later: download again, replace the folder's files, then press Reload on JobHarvest in the extensions page.
